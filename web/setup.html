DesKilo — Assistant de configuration

Un assistant pas à pas : chaque étape ne pose que les questions que vos réponses précédentes rendent possibles (les fonctionnalités que vous n'activez pas, le régime de TVA que vous n'avez pas, le pays qui ne s'applique pas — rien ne vous est demandé pour rien). Chaque question dit où elle se règle dans l'app et renvoie vers le guide. Vos réponses sont enregistrées automatiquement dans ce navigateur. La dernière étape vérifie la cohérence de l'ensemble, puis Exporter le XML produit le fichier : l'app l'importe (Réglages de l'espace → Importer l'espace) pour créer réglages, accessoires et plan ; la section <setup> du même fichier porte tout le reste.

Le guide utilisateur complet — avec une capture de chaque écran, formulaires longs fusionnés en une image — est sur le wiki ↗ (English · Français · Deutsch · Español · Italiano) et dans l'app (Réglages → Aide).

Ne mettez un jeton ou un identifiant ici que si vous remplissez ce document en privé. Le fichier exporté est du texte clair : pour la facturation électronique et les paiements en ligne, vous pouvez laisser les champs vides et saisir les secrets directement dans l'app, où ils partent côté serveur sans jamais en revenir.
