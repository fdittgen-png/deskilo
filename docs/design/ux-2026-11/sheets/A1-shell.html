Anatomy: context line (where I am; role only where it decides what I can do) → one page header (title, count, one primary labelled action, overflow).

What changes and why

  • Observed On pages reached from the sidebar (07, 12, 14, 19) a second bar holds a back arrow and the page tools, under a top bar that already names the page.
  • Decided One persistent shell: sidebar with its existing groups, a context line (business › group › page, role only where it decides what can be done), then ONE page header with title, count, labelled primary action and an overflow menu.
  • Decided No second bar that holds only a back arrow on a page reached from the sidebar; a pushed record page uses the breadcrumb.
  • Decided Phone: one bar with back (or Back to Me), the page title whole, and one overflow button, marked when alerts are behind it.
  • Hypothesis A labelled “New invoice” in the header is found faster than the “+ New” of today; to be checked with a task walk.
