What changes and why

  • Observed Five equal tiles; the next invoice number competes with the actionable deadlines, and the VAT tile shows a period, not a date (12).
  • Observed The breadcrumb repeats the page’s name (12).
  • Decided First block “Due”: filings, unmatched movements with a count, the period’s state; each figure is a link to the records that establish it, with the period and the currency named.
  • Decided Second block “Reference”: next invoice number, journals, exports. The breadcrumb names the page once.
  • Decided A tile that asks for something is outlined in the accent; a tile that only states something is plain. Status uses text as well as colour.
  • Hypothesis Operators look for deadlines first; to be checked with a task walk.
