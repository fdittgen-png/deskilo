What changes and why

  • Observed Result cards carry a description but few comparable facts (23).
  • Observed An icon that registers a directory on a server sits beside the consumer’s List / Map switch (23).
  • Decided Published facts in a comparable row: kind, services, town, open hours.
  • Decided Connecting a server is an “Advanced” action apart from discovering businesses, with its full label.
  • Decided Only facts the businesses publish are shown; an unsupported or unavailable fact says so rather than being left blank.
  • Hypothesis A table at the desk and cards on a phone are enough for comparing three to ten businesses; to be checked with a task walk.
