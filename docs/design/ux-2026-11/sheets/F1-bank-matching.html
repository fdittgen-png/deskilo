What changes and why

  • Observed The bulk button writes at once and only afterwards says how many were confirmed; the person never sees which movement goes to which invoice (13).
  • Observed Nothing is selected when the panes open; the right pane only says to choose a movement (13).
  • Decided One workspace: the statement’s movements left, the selected movement and its candidate invoices right; the first matchable movement is selected on opening.
  • Decided “Confirm 2 matches by reference” opens a confirmation listing each movement → invoice with amount and currency and a total per currency; “Confirm these 2” writes exactly those, Cancel writes nothing.
  • Decided A refusal, or an outcome that covers only some lines, is said per line. A single match keeps the existing match dialog. No cross-currency arithmetic.
  • Hypothesis A reason line under the candidate (“Suggested because the reference matches”) is enough to trust a suggestion; to be checked with a task walk.
